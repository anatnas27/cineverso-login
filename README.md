# Cineverso Login

## Descrição

O Cineverso Login é uma funcionalidade desenvolvida para o sistema Cineverso com o objetivo de realizar a autenticação de usuários utilizando JSON Web Token (JWT).

O projeto foi criado para demonstrar o fluxo de desenvolvimento utilizando Git e GitHub, seguindo boas práticas como criação de branch de funcionalidade, commits e Pull Request.

---

## Objetivo

Implementar uma funcionalidade de login para o sistema Cineverso, permitindo que usuários autenticados possam acessar áreas protegidas da aplicação.

---

## Funcionalidades

- Autenticação de usuários.
- Geração de token JWT (simulação).
- Validação de usuário e senha.
- Retorno de mensagem de sucesso ou erro.

## Fluxo de desenvolvimento

1. Criação da branch `feature/login`.
2. Implementação da autenticação no arquivo `auth.js`.
3. Versionamento das alterações com Git.
4. Envio da branch para o GitHub.
5. Criação de Pull Request para integração na branch `main`.
